## Exported Files

The full assembly is also available as a STEP file for use in any CAD software:

- `NovaPad_Assembly.step` — complete shell assembly (top + bottom halves)

To export individual STL bodies for 3D printing:
1. Open the Onshape document above
2. Right-click `Shell_Top` → Export → STL
3. Right-click `Shell_Bottom` → Export → STL

See `/Print_Files/PRINT_INSTRUCTIONS.md` for recommended print settings and service recommendations.
